# homebrew-tap

Homebrew casks for [Zayn](https://github.com/EryouHao)'s apps.

## Install

```bash
brew install --cask eryouhao/tap/graker
```

## Apps

| Cask | App | What it does |
| --- | --- | --- |
| `graker` | [Graker](https://graker.fehey.com) | Menu bar grammar checker for Chinese English learners |
